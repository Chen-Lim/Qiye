# 安装与更新栖页

## 首次安装

下载源码后，在 Chrome 的 `chrome://extensions` 开启开发者模式，加载 `qiye/extension/`。

也可以解压 `栖页-插件.zip`，直接加载含 `manifest.json` 的目录。

## 已加载扩展但名称仍旧

在扩展详情中核对所加载目录。仅重新加载会刷新该目录中的文件，不会切换到另一个目录。

当前项目的 `extension/manifest.json` 中，`name` 与 `action.default_title` 均为「栖页」。重新加载正确目录后，再新建标签页查看。

如果仍显示其他名称，检查是否有另一个扩展同时接管新标签页；先禁用多余扩展再验证，不必立即卸载。

## 数据保留

同一路径更新并重新加载通常沿用原本地数据。换目录加载可能生成不同的扩展身份，保存的网页和设置不会自动迁移。

本版本支持浏览历史导出，不提供完整保存列表和设置的导入迁移工具。需要保留数据时，先保留已有安装和目录，不要直接卸载。
