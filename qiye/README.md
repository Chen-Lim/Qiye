# 栖页

**给打开的网页一个去处，也给注意力留一点空间。**

栖页（qiye）是一个 Chrome 新标签页扩展。按网站整理当前标签页，把想读的网页保存到稍后查看，阅读后标记已查看，并记录浏览时间。

![栖页工作台，使用演示网页展示界面](docs/assets/workspace.png)

## 能做什么

- **已打开标签页**：按网站自动分组，跨窗口跳转，关闭单页、整组或重复页面。
- **稍后查看**：点击书签保存网页，支持搜索和排序；没有保存或已查看记录时，整个侧栏隐藏。
- **已查看**：勾选后移入可折叠、可搜索的已查看区；取消勾选恢复。打开链接不会删除记录。
- **浏览记录**：查看今日工作时长、网站与标签页用时、历史统计与热力图。
- **专注控制**：专注倒计时、允许访问网站、暂停记录、不计时网站和空闲检测。
- **本地数据**：保存状态跨刷新保留，并在多个新标签页同步；支持浏览历史导出和保留期限设置。
- **主题**：浅色、深色和跟随系统。

无需账号或服务器，扩展运行不需要安装 Node.js。网页图标来自原网站，缺失时显示通用网页图标。

## 安装

1. 下载并解压本仓库，或克隆到本地。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择项目内的 **`extension`** 文件夹。
4. 新建标签页，进入「栖页」。

如果使用打包好的 `栖页-插件.zip`，请解压后加载包含 `manifest.json` 的目录。

升级现有安装时，请更新同一目录中的文件，再点击扩展卡片上的重新加载。Chrome 的本地扩展身份与加载路径有关；改为新目录加载可能形成新的扩展，数据不会自动迁移。

## 开发

```bash
node extension/tests/nodeRunner.mjs
node extension/tests/swSmoke.mjs
python3 scripts/package.py
```

前两条执行回归测试和后台启动检查。第三条在 `dist/` 生成插件压缩包，自动排除测试、缓存与本地配置。

浏览器验收需要 Playwright 和 Chrome，使用独立临时配置，不访问日常浏览器数据：

```bash
node extension/tests/browser-ui.mjs
```

若 Playwright 安装在其他位置，可设置 `PLAYWRIGHT_MODULE` 为其模块入口的绝对路径。截图默认写入系统临时目录，可用 `QIYE_SCREENSHOT_DIR` 指定位置。

## 项目结构

```text
qiye/
├── extension/       # 可直接加载的 Chrome 扩展
│   ├── background/  # 计时、存储、专注控制
│   ├── shared/      # 常量、类型、消息协议
│   ├── ui/          # 界面组件和交互
│   └── tests/       # 回归测试
├── docs/            # 架构、设计决策与安装说明
├── scripts/         # 打包脚本
├── .github/         # 自动化检查
└── LICENSE          # MIT 许可
```
