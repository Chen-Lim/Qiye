# 栖页开发决策

这份文档记录当前版本的约定。源码中的历史里程碑编号保留作注释，不代表当前交付进度。

1. **单一存储入口**：UI 只通过消息操作保存记录，避免多个页面直接写入造成覆盖。
2. **持久化优先**：写入成功后再更新内存和广播；失败时维持已有状态并反馈。
3. **显式阅读状态**：打开链接不自动删除或标记已查看，复选框负责状态流转。
4. **按需显示侧栏**：没有待查看及已查看记录时，隐藏分区并释放宽度。
5. **增量同步**：标签变化增量更新；等价保存快照不替换控件，保留搜索、排序和折叠状态。
6. **单一时间账本**：显示时长、历史统计及预算均由统一计时数据派生。
7. **持久化恢复**：后台可被浏览器暂停，计时和专注状态依赖 alarms 与本地快照恢复。
8. **界面简化**：按网站分组；移除分类及自定义分组设置入口，兼容旧配置数据。
9. **产品标识**：用户界面采用「栖页」，仓库、消息通道和闹钟前缀采用 `qiye`。
10. **保留开源授权**：保留原版权主体、年份、MIT 授权和免责条款。
